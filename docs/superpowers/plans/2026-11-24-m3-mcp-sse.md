**关键决策（实现前先读）：**

1. **SSE 集成必须用真实 uvicorn 代理（127.0.0.1:9910），不能用 ASGITransport**：httpx 0.28 的 `ASGITransport` 把响应体整体积攒到 app 结束才返回（`ASGIResponseStream.__aiter__` 一次性 `b"".join(body_parts)`，`handle_async_request` 要 `await self.app(...)` 跑完）——SSE 永不结束的流会让 ASGI 直连测试**永久挂死**。故 M3 的 SSE 集成测试一律经真实 TCP 访问本服务（session 级夹具，独立线程 loop，复用 echo 上游 9901 的成熟模式）；「客户端断开→上游取消」也只有真实服务器可测。
2. **端口调整（9902 让位 MCP SSE mock，死端口迁到 9909）**：M2 计划把 9902 约定为「不存在的端口」（跨源重定向透传 + probe 上游不可达用例）。本计划 MCP SSE mock 按要求占用 9902——probe 对任意 HTTP 响应判「可达」，9902 有监听会让 `test_http_probe_upstream_down_ok_false` 变绿失败。故 Task 3 先把三处死端口引用（`mock_upstream.py` 跨源重定向、`test_proxy_http.py::test_cross_origin_redirect_passthrough`、`test_mgmt_test_endpoint.py::test_http_probe_upstream_down_ok_false`）迁到 **9909**，再启动 9902。
3. **endpoint 改写 = 增量行解析器（§8.3 实现要点）**：`SseEndpointRewriter.feed(chunk)` 按行切分（保留原始行尾 `\r\n` / `\n`）、跟踪当前 `event:` 名（空行复位）；`event: endpoint` 的 `data:` 行改写为 `data: /p/{id}<path>?<query>`；其余行（message 事件、`retry:`、`:` 心跳注释、字段行）**字节级原样透传**；每行产出即 yield（无整体缓冲）。绝对 URL 形式的 endpoint 值取其 path+query（§8.3 改写规则）；既非绝对 URL 也非根相对的值原样透传（限制说明）。
4. **复用 http 转发管线（§8.5）**：mcp 非 SSE 路径（POST /messages 等）不另起炉灶——`stream_http_forward` 增加 `target_override`（api 层按 origin 根还原算好传入）与 `metrics_type`（标签 type=http/mcp，§15.2）两个参数，重定向跟随/413/502/504/trace/metrics 全部继承。
5. **SSE 读超时不设（§8.1 第 5 条超时表）**：全局 client 的 read=60s 不适用于长连接——`stream_sse_forward` 经 `client.build_request(..., timeout=httpx.Timeout(connect=..., read=None, ...))` 逐请求覆盖（httpx 0.28 已验证支持），依赖上游心跳保活。
6. **trace 的 SSE 落地（§11.1）**：`response` 行在响应头到达即写（time-to-headers，充当「连接建立」记录）；「关闭原因」经运行日志 `log.info`（正常/上游断开/客户端断开）+ `sse_active` gauge 归零表达，**不写第二条 response 行**（同一 request_id 重复 phase=response 会破坏回放语义）；`endpoint` 事件记改写前（`event=endpoint`）+ 改写后（`event=endpoint_rewritten`）两条，`message` 事件记 data 载荷，心跳注释行与 `retry:` 不产生记录。
7. **mcp 分发仅 GET/HEAD 命中注册端点路径时走 SSE 管线**（`stream_sse_forward` 不转发请求体）；其余方法（如 POST /sse）按 origin 根还原走 http 管线——对非根路径 upstream 二者等价 URL，语义由上游决定。

```python
def test_flush_trace_second_drain_catches_in_window_enqueue(tmp_path, monkeypatch):
    """M2 遗留债务 1：第一次排空后、第二次排空前入队的记录不丢。

    受控注入：把 time.sleep 替换为「注入一条迟到记录」的实现——该调用恰好落在
    flush_trace 两次排空之间（确定性复现竞态窗口），单次 flush_trace 即应捕获。
    """
    import json as jsonlib

    from agent_proxy import logging_setup as ls
    from agent_proxy.logging_setup import setup_logging

    setup_logging(str(tmp_path), "INFO")
    produced = {"done": False}
    original_sleep = ls.time.sleep

    def _sleep_then_inject(seconds):
        original_sleep(seconds)  # 必须调原实现（time.sleep 已被替换，直接调会无限递归）
        if not produced["done"]:
            produced["done"] = True
            logging.getLogger("agent_proxy.trace").info(jsonlib.dumps({"phase": "in-window"}))

    monkeypatch.setattr(ls.time, "sleep", _sleep_then_inject)
    logging.getLogger("agent_proxy.trace").info(jsonlib.dumps({"phase": "early"}))
    ls.flush_trace()
    content = "".join(
        p.read_text(encoding="utf-8") for p in sorted(tmp_path.glob("trace.log.*")))
    assert '"phase": "early"' in content
    assert '"phase": "in-window"' in content, "两次排空之间入队的记录应被第二次排空捕获"
```

```python
def flush_trace() -> None:
    """同步排空 trace 队列（测试与停机前调用）。

    二次排空（M2 遗留债务 1）：单次排空与「后台 listener 消费中转 + 生产端
    （响应流 finally 的 trace 写）入队」存在窗口竞态——排空瞬间队列看似空，
    窗口内仍可能有记录入队。排空后等 10ms 让窗口内生产完成，再排一次。
    """
    if _trace_queue is None or _trace_listener is None:
        return
    for _ in range(2):
        while True:
            try:
                record = _trace_queue.get_nowait()
            except queue.Empty:
                break
            if record is _trace_listener._sentinel:
                return  # 取到停止哨兵即停，无后续记录
            _trace_listener.handle(record)
        time.sleep(0.01)
```

```python
"""MCP SSE 传输代理（设计 §8.3）。

纯逻辑部分：路径分发辅助（注册端点路径 / 上游 origin 根还原）与 SSE 增量行
解析器 SseEndpointRewriter——按行读取（保留原始行尾 \\r\\n / \\n）、跟踪当前
`event:` 名（空行复位）；`event: endpoint` 的 data: 行改写为 /p/{id}<path>?<query>
下发，其余行（message 事件 / retry: 行 / `:` 心跳注释行 / 字段行）字节级原样
透传，每行产出即交由管线 yield（每行立即 flush，不做整体缓冲）。

流式转发管线 stream_sse_forward（Task 4）与 test 探测 probe_sse_mapping（Task 6）
同在本模块；trace 记录由解析器产出（take_trace_records），管线层接 trace.log_sse_event。
"""
from __future__ import annotations

from urllib.parse import urlparse


def registered_endpoint_path(upstream_url: str) -> str:
    """注册 upstream_url 的路径（§8.3 路径分发第 1 行的匹配目标）；无路径按根 `/`。"""
    path = urlparse(upstream_url).path
    return path if path else "/"


def build_origin_target(upstream_url: str, sub_path: str, query: str) -> str:
    """非注册端点路径的转发目标：上游 origin 根 + 子路径 [+ ?query]（§8.3 第 2 行）。

    子路径为空时直达 origin 根；query 为调用方原始 query 串（不重编码，透传）。
    """
    parsed = urlparse(upstream_url)
    origin = f"{parsed.scheme}://{parsed.netloc}"
    trimmed = sub_path.lstrip("/")
    if not trimmed:
        return origin
    target = f"{origin}/{trimmed}"
    return f"{target}?{query}" if query else target


class SseEndpointRewriter:
    """SSE 增量行解析器（设计 §8.3 实现要点）。

    feed(chunk) → list[bytes]：本次可产出的完整行（保留原始行尾 \\r\\n / \\n）；
    跨 chunk 的半行在内部缓冲。事件名跟踪按 SSE 语义：`event:` 字段设置当前
    事件名，空行（事件块结束）复位；仅 `event: endpoint` 期间的 data: 行改写。
    take_trace_records() 取走自上次调用以来的 trace 记录
    [(event 名, data 字节), ...]，由管线层接 trace.log_sse_event（body 模式生效）。
    """

    def __init__(self, mapping_id: str) -> None:
        self._mapping_id = mapping_id
        self._buffer = b""
        self._current_event = ""
        self._trace_records: list[tuple[str, bytes]] = []

    def feed(self, chunk: bytes) -> list[bytes]:
        self._buffer += chunk
        lines: list[bytes] = []
        while True:
            idx = self._buffer.find(b"\n")
            if idx < 0:
                break
            line = self._buffer[: idx + 1]           # 含行尾 \n
            self._buffer = self._buffer[idx + 1:]
            lines.append(self._handle_line(line))
        return lines

    def flush(self) -> list[bytes]:
        """流结束时冲出无行尾的残留末行（SSE 允许最后一行无换行）。"""
        rest, self._buffer = self._buffer, b""
        return [self._handle_line(rest)] if rest else []

    def take_trace_records(self) -> list[tuple[str, bytes]]:
        records, self._trace_records = self._trace_records, []
        return records

    def _handle_line(self, line: bytes) -> bytes:
        if line.endswith(b"\r\n"):
            body, ending = line[:-2], b"\r\n"
        elif line.endswith(b"\n"):
            body, ending = line[:-1], b"\n"
        else:
            body, ending = line, b""
        text = body.decode("utf-8", "replace")
        if text.startswith(":"):
            return line                              # 心跳注释行：字节级透传，不记 trace
        if text.startswith("event:"):
            self._current_event = text[len("event:"):].strip(" ")
            return line
        if text == "":
            self._current_event = ""                 # 空行 = 事件块结束，事件名复位
            return line
        if text.startswith("data:") and self._current_event == "endpoint":
            return self._rewrite_endpoint_data(text, ending)
        if text.startswith("data:"):
            # message（或未具名事件）的 data 载荷：透传原行 + 产 trace 记录
            self._trace_records.append(
                ("message", text[len("data:"):].lstrip(" ").encode("utf-8")))
        return line                                  # 其余（id:/retry:/字段行）透传

    def _rewrite_endpoint_data(self, text: str, ending: bytes) -> bytes:
        raw_value = text[len("data:"):]
        value = raw_value[1:] if raw_value.startswith(" ") else raw_value
        parsed = urlparse(value)
        if parsed.netloc:                            # 绝对 URL：取 path + query（§8.3 改写规则）
            path_query = parsed.path or "/"
            if parsed.query:
                path_query = f"{path_query}?{parsed.query}"
        elif value.startswith("/"):                  # 根相对路径（官方 SDK 形态）
            path_query = value
        else:                                        # 限制说明：其余值不改写，原样透传
            return text.encode("utf-8") + ending
        rewritten = f"/p/{self._mapping_id}{path_query}"
        self._trace_records.append(("endpoint", value.encode("utf-8")))
        self._trace_records.append(("endpoint_rewritten", rewritten.encode("utf-8")))
        return f"data: {rewritten}".encode("utf-8") + ending
```

```python
- GET /sse-no-endpoint：只发心跳、永不发 endpoint 事件（test 接口「握手失败」用例）；
- GET /_connections：调试端点，返回当前活跃 SSE 连接数（客户端断开→上游取消
  的端到端验证用）。

模块级 mock_state 供测试直读（received 断言出站 header/query；测试自行清空）。
"""
from __future__ import annotations

import asyncio
import json

from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse, Response, StreamingResponse

# 模块级状态：测试直接 import 断言
mock_state: dict = {"sse_open": 0, "received": [], "queues": []}


def _result_for(rpc: dict) -> dict:
    method = rpc.get("method")
    if method == "initialize":
        params = rpc.get("params") or {}
        return {"protocolVersion": params.get("protocolVersion", "2025-06-18"),
                "capabilities": {"tools": {}},
                "serverInfo": {"name": "mock-mcp-sse", "version": "0.1.0"}}
    if method == "tools/list":
        return {"tools": [{"name": "echo",
                           "description": "回显输入文本",
                           "inputSchema": {"type": "object",
                                           "properties": {"text": {"type": "string"}}}}]}
    if method == "tools/call":
        args = (rpc.get("params") or {}).get("arguments") or {}
        return {"content": [{"type": "text", "text": json.dumps(args, ensure_ascii=False)}]}
    return {"echo": method}


def build_mcp_sse_app() -> FastAPI:
    app = FastAPI(docs_url=None, redoc_url=None, openapi_url=None)

    @app.get("/sse")
    async def sse_endpoint():
        queue: asyncio.Queue = asyncio.Queue()
        mock_state["queues"].append(queue)
        mock_state["sse_open"] += 1

        async def gen():
            try:
                yield b"event: endpoint\ndata: /messages?session_id=test123\n\n"
                while True:
                    try:
                        payload = await asyncio.wait_for(queue.get(), timeout=0.2)
                        yield f"event: message\ndata: {payload}\n\n".encode("utf-8")
                    except asyncio.TimeoutError:
                        yield b": ping\n\n"   # 心跳注释行（§8.3：代理透传不记录）
            finally:
                mock_state["sse_open"] -= 1
                if queue in mock_state["queues"]:
                    mock_state["queues"].remove(queue)

        return StreamingResponse(gen(), media_type="text/event-stream")

    @app.get("/sse-no-endpoint")
    async def sse_no_endpoint():
        async def gen():
            while True:
                yield b": heartbeat only, no endpoint event\n\n"
                await asyncio.sleep(0.2)

        return StreamingResponse(gen(), media_type="text/event-stream")

    @app.post("/messages")
    async def messages(request: Request):
        rpc = json.loads(await request.body())
        mock_state["received"].append({
            "rpc": rpc,
            "query": dict(request.query_params),
            "headers": dict(request.headers.items()),
        })
        if "id" in rpc:  # notifications 无 id：只收不回（MCP 规范）
            payload = json.dumps({"jsonrpc": "2.0", "id": rpc["id"],
                                  "result": _result_for(rpc)}, ensure_ascii=False)
            for queue in list(mock_state["queues"]):
                queue.put_nowait(payload)
        return Response(status_code=202)

    @app.get("/_connections")
    async def connections():
        return JSONResponse({"sse_open": mock_state["sse_open"]})

    return app
```

```python
async def stream_sse_forward(app_state, mapping_data: dict, request: Request) -> Response:
    """MCP SSE 初始连接转发（设计 §8.3）：GET/HEAD 注册端点 → upstream_url 真流式
    长连接，endpoint 事件增量改写，其余行字节级透传，每行产出即 yield。

    读超时不设（§8.1 第 5 条，依赖上游心跳保活）；非 200 / 非 text/event-stream
    响应（上游错误体等）不进入改写管线，原样流式回传且不计 sse_active；
    客户端断开由 ASGI 取消生成器 → finally 关闭上游连接（§8.1 第 4 条）。
    本函数不转发请求体（调用方仅 GET/HEAD 分发至此）。
    """
    settings = app_state.settings
    client: httpx.AsyncClient = app_state.http_client
    mapping_id = mapping_data["mapping_id"]
    request_id = request.state.request_id
    uid = request.state.uid

    sub_path = split_sub_path(request.scope["path"], mapping_id)  # 与 api 层同检（双保险）
    assert_safe_sub_path(sub_path)
    target = build_forward_target(mapping_data["upstream_url"], "", request.url.query)
    outbound = build_outbound_headers(
        mapping_data["upstream_headers"] or {}, dict(request.headers.items()),
        content_type=request.headers.get("content-type"),
        content_length=request.headers.get("content-length"),
        content_encoding=request.headers.get("content-encoding"))

    def _log_request() -> None:
        trace.log_request(request_id, uid, mapping_id, request.method, target, outbound,
                          body=b"", body_bytes=0)

    start = time.monotonic()
    # SSE 长连接：读超时不设（read=None，§8.1 第 5 条超时表），connect/pool 沿用全局
    timeout = httpx.Timeout(connect=settings.upstream_connect_timeout, read=None,
                            write=60.0, pool=settings.upstream_pool_timeout)
    req = client.build_request(request.method, target, headers=outbound, timeout=timeout)
    try:
        upstream_resp = await client.send(req, stream=True)
    except httpx.PoolTimeout as exc:  # 池上限（必须先于 TimeoutException 捕获）
        metrics.upstream_errors_total.labels(type="mcp", code="pool_exhausted").inc()
        _log_request()
        raise AppError(503, "PROXY_BUSY", "上游连接池已满，请稍后重试") from exc
    except httpx.TimeoutException as exc:
        metrics.upstream_errors_total.labels(type="mcp", code="timeout").inc()
        _log_request()
        raise AppError(504, "UPSTREAM_TIMEOUT", f"上游超时: {exc}") from exc
    except httpx.HTTPError as exc:
        metrics.upstream_errors_total.labels(type="mcp", code="connect").inc()
        _log_request()
        raise AppError(502, "UPSTREAM_ERROR", f"上游连接失败: {exc}") from exc
    _log_request()

    status = upstream_resp.status_code
    resp_ct = next((v for k, v in upstream_resp.headers.items()
                    if k.lower() == "content-type"), "")
    # duration_ms 语义：time-to-headers（trace response 行充当「连接建立」记录）
    duration_ms = int((time.monotonic() - start) * 1000)
    metrics.upstream_duration.labels(type="mcp").observe(duration_ms / 1000)

    resp_headers = filter_response_headers(upstream_resp.headers)
    if not any(k.lower() == "x-accel-buffering" for k in resp_headers):
        resp_headers["X-Accel-Buffering"] = "no"          # 网关关闭缓冲（§8.1 第 9 条）

    is_sse = status == 200 and "text/event-stream" in resp_ct.lower()
    trace.log_response(request_id, status, duration_ms)

    if not is_sse:
        # 非 SSE 响应（上游 4xx/5xx 错误体等）：不改写、不计 sse_active，原样流式回传
        async def _plain_stream():
            try:
                async for chunk in upstream_resp.aiter_bytes(_SSE_CHUNK):
                    yield chunk
            finally:
                await upstream_resp.aclose()
        return StreamingResponse(_plain_stream(), status_code=status, headers=resp_headers)

    rewriter = SseEndpointRewriter(mapping_id)
    metrics.sse_active.inc()

    async def _sse_stream():
        try:
            async for chunk in upstream_resp.aiter_bytes(_SSE_CHUNK):
                lines = rewriter.feed(chunk)
                for event, data in rewriter.take_trace_records():
                    trace.log_sse_event(request_id, event, data)   # 仅 body 模式生效
                for line in lines:
                    yield line            # 每行立即下发（无整体缓冲，§8.3 实现要点）
            tail = rewriter.flush()
            for event, data in rewriter.take_trace_records():
                trace.log_sse_event(request_id, event, data)
            for line in tail:
                yield line
        except httpx.HTTPError as exc:
            metrics.upstream_errors_total.labels(type="mcp", code="stream_broken").inc()
            log.exception("上游 SSE 流中断: %s", exc)
            raise
        finally:
            metrics.sse_active.dec()
            await upstream_resp.aclose()                  # 客户端断开→取消上游（§8.1 第 4 条）
            log.info("SSE 连接关闭: request_id=%s mapping_id=%s 总时长=%dms",
                     request_id, mapping_id, int((time.monotonic() - start) * 1000))

    try:
        return StreamingResponse(_sse_stream(), status_code=status, headers=resp_headers)
    except BaseException:
        metrics.sse_active.dec()                          # 生成器未启动的交棒窗口防泄漏
        await upstream_resp.aclose()
        raise
```

```python
"""代理端点 /p/{mapping_id}/{path}（设计 §6.2 / §8.2 / §8.3）。

管线：JWT 鉴权 → load_mapping → 可见性（private 仅注册者；public 任意有效身份）→
status=active 拦截（disabled → 404 隐藏）→ 按映射 type 分发：
- http：前缀拼接流式转发（§8.2）；
- mcp：GET/HEAD 且命中注册端点路径 → SSE 初始连接（endpoint 事件改写，§8.3 第 1 行）；
  其余方法/路径按上游 origin 根还原，复用 http 流式管线（§8.3 第 2 行 / §8.5 统一骨架）。
"""
from __future__ import annotations

from fastapi import APIRouter, Depends, Request, Response

from ..auth import Identity
from ..config import Settings, get_settings
from ..errors import AppError
from ..forward.http_forward import (assert_safe_sub_path, split_sub_path,
                                    stream_http_forward)

                               stream_sse_forward)

_PROXY_METHODS = ["GET", "POST", "PUT", "PATCH", "DELETE", "HEAD", "OPTIONS"]


async def _handle_proxy(request: Request, mapping_id: str, identity: Identity,
                        settings: Settings) -> Response:
    # DB session 只包住 load_mapping（评审 Important 项）：不走 get_db 依赖——其
    # teardown 在响应发完才执行，SSE/长流会把连接占死（池 10 → ~20 并发即排队）。
    # load_mapping 返回脱管 dict（row_to_dict），session 早关安全。
    async with request.app.state.sessionmaker() as session:
        data = await load_mapping(session, request.app.state.redis, mapping_id,
                                  settings.cache_ttl)
    if data is None:
        raise AppError(404, "MAPPING_NOT_FOUND", "映射不存在")
    # 审计 mapping_id 对后续所有分支生效（含 403/禁用 404）
    request.state.mapping_id = mapping_id
    # metrics type 标签（§15.2 http/mcp；中间件回读 state）
    request.state.proxy_type = "mcp" if data["type"] == "mcp" else "http"
    if data["visibility"] == "private" and data["owner_uid"] != identity.user_id:
        raise AppError(403, "FORBIDDEN", "仅注册者可调用该映射")
    # visibility=public：任意有效身份放行（M6 内置映射场景；M3 数据中不出现 public 用户映射）
    if data["status"] != "active":
        raise AppError(404, "MAPPING_NOT_FOUND", "映射不存在或已禁用")
    if data["type"] == "mcp":
        # 路径分发（§8.3 表）：仅 GET/HEAD 且命中注册端点路径 → SSE 初始连接
        # （stream_sse_forward 不转发请求体，故非 GET/HEAD 不走此分支）；其余
        # 路径按上游 origin 根还原后复用 http 流式管线
        sub_path = split_sub_path(request.scope["path"], mapping_id)
        assert_safe_sub_path(sub_path)
        if request.method in ("GET", "HEAD") and \
                sub_path == registered_endpoint_path(data["upstream_url"]):
            return await stream_sse_forward(request.app.state, data, request)
        target = build_origin_target(data["upstream_url"], sub_path, request.url.query)
        return await stream_http_forward(request.app.state, data, request,
                                         target_override=target, metrics_type="mcp")
    return await stream_http_forward(request.app.state, data, request)


@router.api_route("/p/{mapping_id}/{path:path}", methods=_PROXY_METHODS)
async def proxy_with_path(request: Request, mapping_id: str, path: str,
                          identity: Identity = Depends(get_current_identity),
                          settings: Settings = Depends(get_settings)) -> Response:
    return await _handle_proxy(request, mapping_id, identity, settings)


# 注（M2 评审 5d 不采纳，保留）：proxy_root 并非死路由——`{path:path}` 路由的正则

@router.api_route("/p/{mapping_id}", methods=_PROXY_METHODS)
async def proxy_root(request: Request, mapping_id: str,
                     identity: Identity = Depends(get_current_identity),
                     settings: Settings = Depends(get_settings)) -> Response:
```

```python
async def probe_sse_mapping(app_state, mapping_data: dict) -> dict:
    """mcp+SSE 类型 test（设计 §6.6）：GET 注册端点读流，收到 text/event-stream +
    首个 endpoint 事件即通过；随后立即断开（不维持长连接）。

    复用转发管线的出站 header 重建（测的即真实路径）；上游失败一律 ok=false +
    detail，不抛 502/504；endpoint 值经 redact_query 脱敏后进 detail
    （session_id 不落日志明文，与 trace query 脱敏同规）。
    OAuth 绑定用户（M6）以本人凭证走同一规则：注入 Authorization 后复用本函数。
    """
    stored = mapping_data["upstream_headers"] or {}
    headers = build_outbound_headers(stored, {"Accept": "text/event-stream"},
                                     None, None, None)
    target = mapping_data["upstream_url"]
    start = time.monotonic()

    def _result(ok: bool, status_code: int | None, detail: str) -> dict:
        return {"ok": ok, "status_code": status_code,
                "latency_ms": int((time.monotonic() - start) * 1000), "detail": detail}

    client: httpx.AsyncClient = app_state.http_client
    try:
        req = client.build_request("GET", target, headers=headers,
                                   timeout=TEST_PROBE_TIMEOUT)
        resp = await asyncio.wait_for(client.send(req, stream=True), TEST_PROBE_TIMEOUT)
    except asyncio.TimeoutError as exc:  # 3.11+ 即内置 TimeoutError（wait_for 总期限）
        return _result(False, None,
                       f"上游超时（>{TEST_PROBE_TIMEOUT:.0f}s 总期限）: {type(exc).__name__}")
    except httpx.TimeoutException as exc:  # 分项超时先到（connect/read/pool）
        return _result(False, None, f"上游超时（>{TEST_PROBE_TIMEOUT:.0f}s）: {type(exc).__name__}")
    except httpx.HTTPError as exc:
        return _result(False, None, f"上游不可达: {type(exc).__name__}: {exc}")

    status_code = resp.status_code
    content_type = next((v for k, v in resp.headers.items()
                         if k.lower() == "content-type"), "")
    if status_code != 200 or "text/event-stream" not in content_type.lower():
        await resp.aclose()
        return _result(False, status_code,
                       f"非 SSE 响应（status={status_code}，content-type={content_type or '无'}）")

    async def _first_endpoint() -> str | None:
        buf = b""
        current_event = ""
        async for chunk in resp.aiter_bytes():
            buf += chunk
            while b"\n" in buf:
                line, _, buf = buf.partition(b"\n")
                text = line.decode("utf-8", "replace").rstrip("\r")
                if text.startswith("event:"):
                    current_event = text[len("event:"):].strip()
                elif text.startswith("data:") and current_event == "endpoint":
                    return text[len("data:"):].strip()
        return None

    try:
        endpoint_value = await asyncio.wait_for(_first_endpoint(), TEST_PROBE_TIMEOUT)
    except asyncio.TimeoutError:
        await resp.aclose()
        return _result(False, status_code,
                       f"未在 {TEST_PROBE_TIMEOUT:.0f}s 内收到 endpoint 事件（非 MCP SSE 端点？）")
    await resp.aclose()  # 首个 endpoint 事件即断开（§6.6）
    if endpoint_value is None:
        return _result(False, status_code, "流结束仍未收到 endpoint 事件")
    return _result(True, status_code,
                   f"SSE 握手成功（endpoint={trace.redact_query(endpoint_value)}）")
```

### M3 已知限制（明示接受，均有代码注释对应）

1. **endpoint 值形态**（§8.3 限制说明）：仅改写根相对路径与绝对 URL（取 path+query）；其余值原样透传。
2. **upstream_url 自带 query**：初始连接拼接会出现 `...?a=1?b=2` 形态（与 M2 http 类型同款接受；注册建议不含 query）——build_forward_target 行为未变。
3. **注册端点路径精确匹配**：`/sse` 与 `/sse/` 视为不同（不做尾斜杠规范化）；非 GET/HEAD 到注册端点路径走 origin 根还原（非根路径 upstream 时 URL 等价）。
4. **代理不自动重连 SSE**：重连是客户端语义（Inspector/SDK 自带）；`Last-Event-ID` / `Mcp-Session-Id` / `MCP-Protocol-Version` 白名单透传已在 M2 备好（test_headers 单测覆盖）。
5. **SSE 半开连接**（客户端异常消失）依赖 TCP keepalive（设计 §9.10 已知限制，一期不设最长连接时长）。
6. **trace「关闭原因」落地方式**：response 行在连接建立时写（time-to-headers）；关闭经运行日志 + `sse_active` gauge 表达，不写第二条 response 行（同 request_id 唯一 response 行，回放语义不变）。
7. **Inspector 联调为人工步骤**（`scripts/inspector_m3.md`）；协议级已自动化（裸 httpx SSE 客户端），不引入 e2e 依赖 Node 的 CI 步骤。
8. **mock 上游消息广播**：mock 对所有活跃 SSE 连接广播 message（非严格会话隔离）——集成测试为顺序单连接，不影响断言有效性。
9. **accept-encoding 透明性**（评审 Issue 4，立仓库级 backlog）：转发管线经 httpx `aiter_bytes` 读上游——上游若返回压缩体，httpx 会按出站 `Accept-Encoding` **自动解压**，而响应头按原样透传（含上游的 `content-encoding: gzip` 与按压缩字节计的 `content-length`）→ 头与体不一致，严格客户端（h11）可能报错。现网暴露条件：上游默认做 gzip 压缩。**修复方向（二选一，波及 M2 `_response_stream` 与 M3 SSE 管线，M4 前统一处理）**：① 改用 `aiter_raw()` 透传压缩字节（头体一致，不解压）；② 出站钉 `accept-encoding: identity`（禁压缩，头体一致且明文）。当前未观测到失败（测试上游不压缩），记录为已知限制。
